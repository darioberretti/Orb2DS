Use this file for contrastive examples that teach a decision rather than a surface voice. When adding the first example, remove the sentence above and add an index of active examples at the top.

Use the following structure for every example:

## EX-001 — Short descriptive title

**Applies to**

Identify the document type, section, audience, and operation.

**Context and goal**

Explain what the passage must accomplish and any constraints needed to judge it.

**Old**

> Insert the original or rejected version.

**New**

> Insert the preferred version.

**Why the new version is better**

- Identify the substantive improvements.
- Name any formulaic pattern removed.
- Explain why a sentence was cut, retained, reordered, or made more explicit.

**Technical content preserved**

- List the claims, terminology, numbers, equations, citations, qualifications, or distinctions that must remain unchanged.

**Rules illustrated**

- Link the example to the relevant numbered general principles, technical requirements, or additional rules.

**Limits**

State where the example should not be generalized. An example is evidence about a decision boundary, not a template to copy.

Prefer a small set of carefully judged contrasts over a large uncurated corpus. Include examples from different sections, audiences, and editing operations. Do not add an example unless the preferred version is one the user would actually accept.
